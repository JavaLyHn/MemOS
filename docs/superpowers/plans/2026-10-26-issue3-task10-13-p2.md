## Rulings
- KB has immutable upstream home namespace; sharing is an explicit local association, not moving/duplicating an upstream object. Association/full replacement requires owners on all affected projects and the KB home. Reads expose only caller-visible project IDs. Global mutations require editor on all linked/home projects, deletion owner. Inactive home blocks access; unlink and entity deletion are distinct. Orphan KBs remain manageable by their home owner.
- New KB without project selection uses current session workspace. Existing upstream KBs are discovered only through authorized namespaces; a registry row is never accepted as proof of upstream entity existence.
- Files accept bounded Data URL or literal UTF8 text, never remote URLs/path traversal. Canonical base64 transport prevents text decoding ambiguity. Ordinary document storage only; NoopIngestor is not parsing/chunking/recall.
- Prompt detail is readable; save/reset owner and generate/debug editor (paid inference). Preserve ${conversation}. Runtime saved-rule proof uses an isolated synthetic project and minimal genuine extraction, never changes existing user prompts.
- Graph uses activated tenant-scoped upstream graph; <=120-char labels and correct truncation, bounded nodes/edges/response. Full-text lookup must use same source. Model response is a strict allowlist with endpoint credentials/query/fragment stripped or rejected, never local env/static guesses.
