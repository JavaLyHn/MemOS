# 登录界面与 Task15 设计

用户要求先美化登录/登出，再实现属性树模板加分任务；由主 agent 完成，不提交代码，不修改 src/。

## 界面

沿用控制台浅灰画布、白卡片、紫色按钮和冷灰文字。选择居中窄卡片，优于大幅插图或双栏营销布局，更适合简洁的管理控制台。提供品牌、标题、说明、显式标签、完整宽度按钮、键盘焦点与手机布局。退出页提供返回控制台入口。复用后端 HTML，保持登录重定向、会话、CSRF、同源和表单行为。CSS 使用 CSP 内容哈希授权，不放宽脚本策略，不依赖外部资源。

## Task15

以 openapi.json 的五个 profileTemplate 接口为准，复用上游 profile_template 原生 CRUD，项目 ID 由控制存储解析，读需 viewer，写需 owner。详情必须验证归属，分页投影为 list/current/size/total/pages，字段树在后端严格校验并映射上游格式，拒绝伪造系统字段及越权。复用上游持久化，不另建假数据源。当前前端 ComingSoon/禁用菜单保留，在报告中明确只能通过 API 使用。

验收包括认证权限、两项目隔离、树结构、分页、真实上游同 ID 对照、持久化和清理测试数据。若发现上游不支持契约中的能力，明确记录而不伪造成功。
