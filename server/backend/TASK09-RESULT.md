## 已交付

- 团队邀请列表/创建、角色修改、撤销。角色严格为viewer/editor/owner，默认有效168h；expiresIn接受正整数s/m/h，最长30天，与现有UI的1/7/14/30天选择兼容。
- 明文令牌仅创建时在`path`返回一次；库保存随机token摘要，列表不返回路径或令牌。默认Uvicorn入口关闭原始URL访问日志，避免邀请路径落盘。
- `/__login/invite/{token}` 后端落地页支持当前账号接受；未登录者可注册新账号并接受，已有账号可跳转登录后回到该邀请。使用现有Vite `/__login` 代理，不改React。
- 创建、修改、撤销仅owner/管理员；接受是有效邀请能力授权，提交仍需CSRF及Origin校验。密码与账号创建沿用Task07规则，注册失败与邀请消费同事务回滚。
- 接受时重新检查令牌摘要、到期、撤销、已用及项目活跃状态。BEGIN IMMEDIATE原子写入成员及已使用状态；并发两个账号只能一个成功。成功会选中新加入项目。
- 已有成员接受返回409、邀请不消耗、原角色不变，防止被viewer邀请静默降级。已使用/撤销409、过期410、未知或不可访问404。创建者账号删除保留团队邀请但清空引用；已使用者删除不让邀请重新有效。
