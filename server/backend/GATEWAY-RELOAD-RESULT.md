# 网关密钥自动重载

2026-10-27，用户授权新增“检测配置变化并自动重载”。仅主 agent 实现；没有修改前端、数据库结构或上游记忆服务 API，没有新增依赖，也没有提交代码。

## 行为

网关已升级并受控重启一次。之后控制台密钥新增/撤销成功发布后，下一次 HTTP 鉴权请求自动生效，不需要重启网关。改名不改变凭据或配置字节，不会中断鉴权。MEMOS_TENANTS 环境变量、网关代码或启动配置的变化仍需重启。

请求级检测读取文件身份、大小、纳秒修改/变更时间和 pending 标记；没有变化时不重新解析。变化时复用 Dashboard 发布锁，以非阻塞方式读取确认文件，比较读取前后指纹并一次替换完整映射。鉴权中的文件操作在线程池执行，不阻塞异步事件循环，不启动额外后台监听进程。

文件损坏、丢失、无读取权限、与环境映射冲突、发布锁忙或 pending 时，拒绝文件来源的密钥，避免继续接受可能已撤销的旧密钥。环境来源的独立身份保持可用，后续确认发布自动恢复。空文件不关闭鉴权。删除文件里的重复映射不能撤销环境变量中的同一凭据，环境变量仍独立有效。

已经完成鉴权的请求允许结束，不承诺取消正在执行的工具。公开 health/落地页不触发重载，租户数量反映最近一次鉴权快照。多 worker 各自在下一次请求检查共享文件。

## 人工操作

在接口密钥页新建一把测试密钥，直接用其调用网关即可，不运行 Restart-Gateway.ps1；撤销后下一次请求应401。改名后同一密钥仍可调用。不要把401的撤销测试预期误当成网关故障。故障配置请先恢复Dashboard已提交状态，再重试鉴权，勿通过取消pending或关闭鉴权绕过发布确认。
